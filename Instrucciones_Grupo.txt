======================================================
GUÍA DE INSTALACIÓN Y PRUEBA - PROYECTO PEGASO (GRUPO 6)
======================================================

PASO 1: DESCARGAR EL PROYECTO
1. Clonen el repositorio de GitHub o descarguen el ZIP desde:
   https://github.com/1Mejor2345/SBD_2P.git
2. Extraigan los archivos y abran la carpeta principal "pegaso" en Visual Studio Code.

PASO 2: CONFIGURAR LA BASE DE DATOS (MySQL Workbench)
1. Abran MySQL Workbench e inicien sesión en su conexión local (root).
2. Abran y ejecuten UNO POR UNO los siguientes scripts que se encuentran en la carpeta "database", estrictamente en este orden:
   - 01_pegaso_schema.sql (Crea la estructura de tablas)
   - 02_pegaso_indexes.sql (Crea los índices para optimización)
   - 03_pegaso_views.sql (Crea las vistas)
   - 04_pegaso_procedures.sql (Crea los stored procedures)
   - 05_pegaso_triggers.sql (Crea los triggers de auditoría)
   - 06_pegaso_seed.sql (Inserta los datos de prueba)
3. Opcional pero recomendado: Verifiquen que la base de datos `pegaso_airlines` aparezca en el panel izquierdo de Schemas y contenga las tablas.

PASO 3: CONFIGURAR EL ARCHIVO .env
1. En Visual Studio Code (dentro de la carpeta del proyecto), busquen el archivo llamado `.env`
2. Abran el archivo y asegúrense de que las credenciales coincidan con su MySQL local.
   EJEMPLO DE CÓMO DEBE QUEDAR:
   MYSQL_HOST=localhost
   MYSQL_USER=root
   MYSQL_PASSWORD=root  <-- (Cambien 'root' por la contraseña que ustedes usen en MySQL Workbench. Si no tienen contraseña, déjenlo vacío: MYSQL_PASSWORD=)
   MYSQL_DATABASE=pegaso_airlines

PASO 4: INSTALAR DEPENDENCIAS (LIBRERÍAS)
1. En Visual Studio Code, abran una nueva terminal (Terminal -> New Terminal).
2. Ejecuten el siguiente comando para instalar Flask y el conector de MySQL:
   pip install -r requirements.txt

PASO 5: EJECUTAR EL SERVIDOR
1. En la misma terminal de VS Code, ejecuten:
   python app.py
2. Verán un mensaje que dice "Running on http://127.0.0.1:5000".
3. Abran su navegador web (Chrome, Edge, Firefox, etc.) y vayan a esa dirección: http://127.0.0.1:5000

PASO 6: CÓMO PROBAR TODO EL SISTEMA (PASO A PASITO PARA EL VIDEO/SUSTENTACIÓN)
El sistema cuenta con un diseño premium y validaciones reales en la base de datos. Para probarlo y mostrárselo a la profesora, sigan este flujo exacto:

--- A. INICIO DE SESIÓN ---
Pueden usar cualquiera de estos usuarios de prueba (todos tienen la misma contraseña que su nombre de usuario):
- Administrador: usuario "admin" / contraseña "admin"
- Agente: usuario "agente" / contraseña "agente"
- Supervisor: usuario "supervisor" / contraseña "supervisor"

--- B. PRUEBA DE RESERVACIONES (CRUD 1) ---
1. Entren al sistema web y vayan al menú "Reservaciones".
2. Den clic en "Nueva Reservación".
3. Busquen un vuelo (Ej: origen UIO a destino GYE).
4. Llenen los datos ficticios del pasajero y compren el boleto.
5. El sistema web les dará un mensaje de éxito verde con un código PNR de 6 letras.
6. ¡Prueba para la miss!: Vayan a MySQL Workbench y ejecuten `SELECT * FROM reservaciones;`. Expliquen: "Aquí mostramos cómo la página web se conecta exitosamente y el *Stored Procedure* insertó la reserva de manera segura."

--- C. PRUEBA DE CHECK-IN (CRUD 2) ---
1. En la página web, vayan al menú "Check-In".
2. Busquen la reserva que acaban de crear usando el código PNR.
3. Se les abrirá un MAPA DE ASIENTOS gráfico cuadriculado interactivo.
4. Seleccionen un asiento que esté marcado como "Disponible" y confirmen el Check-in. El sistema generará el Pase de Abordar.
5. ¡Prueba para la miss!: En Workbench, ejecuten `SELECT * FROM asientos_vuelo;` y busquen el asiento seleccionado. Expliquen: "El sistema actualiza en tiempo real el estado del asiento a 'OCUPADO', previniendo el Overbooking directamente desde la base de datos."

--- D. GESTIÓN DE VUELOS Y SOFT-DELETE (CRUD 3) ---
1. En la página web, vayan al menú "Vuelos".
2. Seleccionen la opción para editar/cambiar el estado de un vuelo (Ej: cambiar de PROGRAMADO a CANCELADO).
3. ¡Prueba para la miss!: Vayan a Workbench y ejecuten `SELECT * FROM auditoria;`. Expliquen: "Cumpliendo con las reglas de negocio de una aerolínea, no hacemos DELETE físico para no corromper la historia. Cambiamos el estado (eliminación lógica) y un *Trigger* silencioso graba esta acción en la tabla de auditoría por seguridad."

¡Con estos pasos y explicaciones tienen asegurada la mejor calificación en el proyecto!
